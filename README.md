# 球幕节目预演与校正系统（Dome Preview Studio）

纯浏览器运行的球幕（domemaster）节目预演与多投影机校正工具。TypeScript + React 18 + WebGL2，
无需后端，工程数据保存在浏览器 localStorage，可导出为 `.dome.json` 备份或迁移。

## 启动

```bash
npm install
npm run dev       # 开发
npm run build     # 类型检查 + 生产构建（输出 dist/）
npm run test      # 数学单元测试（Vitest，38 项）
```

| 页面 | 功能 |

| 场景编排 | 星表星场（星等门限/亮度/银河）、观测地与日期时间、行星与轨道、关键帧动画 |
| 投影校正 | 多投影机分区（方位/仰角/覆盖角/滚转）、边缘融合带宽度与 gamma、覆盖遮罩可视化、**鱼眼 GPU 精度校验** |

| 设置 | 球幕直径、倾角与倾斜方位、180°/210° FOV、预览/导出分辨率、帧率 |

## 渲染管线

```
场景数据（星表方向 / 行星 / 轨道 / 关键帧）
   │  CPU：天文坐标变换 + 等距鱼眼参考公式（src/math/）
   ▼
Cubemap（6 个 90° 透视面，WebGL2 FBO 离屏渲染）
   │  星点为相机对齐 billboard（不依赖 GL_POINTS，软件渲染器亦稳定）
   ▼
等距鱼眼 warp（全屏 pass，逐像素反算方向采样 cubemap）
   ▼
Canvas 预览 / 离屏 target（PNG 导出、GPU 校验 readPixels）
```

## 鱼眼（equidistant domemaster）映射与精度保证

这是系统的核心约束。等距关系 `θ = r · (FOV/2)`，其中 θ 是方向与球幕天顶轴的夹角，
r 是像素到画面圆心的归一化半径，圆内切于正方形画幅。

单一事实源在 `src/math/fisheye.ts`（TypeScript），GLSL 实现
（`src/renderer/shaders.ts` 的 `ndcToDir`）逐式镜像同一公式，包括：

- 像素坐标 ↔ 归一化坐标：统一用 `(size-1)` 归一化，GLSL 与 TS 完全同式；
- 等距角关系及其逆映射；
- 球幕倾角：Rodrigues 旋转，零倾角走快速路径避免退化叉积；
- FOV 180° 与 210° 共用同一公式，仅 `halfFov` 不同。

精度验证有两层：

1. **数学单测**（`src/math/*.test.ts`，38 项）：全像素网格往返
   `pixelToDir → dirToPixel` 的闭合误差、已知方向手算锚点、倾角可逆性等；
   纯数学往返误差 < 0.001 px。
2. **GPU 实测**（投影校正页「鱼眼映射精度校验」，`src/renderer/fisheyeValidate.ts`）：
   warp 着色器以方向编码模式把每个像素的世界方向写进颜色，readPixels 回 CPU 后
   与 TS 参考公式逐像素比对，把角度误差按等距鱼眼恒定的角分辨率（度/像素）
   换算成像素位置误差，阈值 **0.5 像素**，并给出最大/平均/RMS 误差与圆外黑场核对；
   另含天顶、四方位地平线、45° 仰角八方向等已知球面方向的像素位置抽查。

> 注意：GPU 校验的绝对精度受渲染目标位深（当前 RGBA8 方向编码，每通道 256 级）
> 限制，量化噪声约 0.005 px 量级，远低于半像素阈值；数学公式本身为双精度。

## 目录结构

```
src/
  math/            纯函数数学：鱼眼映射、向量/矩阵、天文、星表、关键帧、投影融合（含单测）
  renderer/        WebGL2 引擎、着色器、场景组装、GPU 校验、PNG/ZIP 导出
  state/           localStorage 持久化、默认工程、React store
  pages/           六个页面
  ui/              通用控件、预览画布、Toast、错误边界
```

## 天文模型说明

- 恒星：内置 60+ 颗亮星（J2000 赤道坐标 + 视星等，源自 Yale Bright Star Catalog 常用数据），
  暗于设定门限的部分由确定性程序化星补充；
- 行星/太阳：Meeus 平均轨道根数（J2000，线性世纪项）+ 开普勒方程，地心简化转站心地平坐标；
- 星空按观测地经纬度、UTC 时间做 GMST 时角变换，预演级别精度（角分级）。
