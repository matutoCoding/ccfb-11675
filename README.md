# 球幕节目预演与校正系统

天文馆球幕(fulldome)节目的浏览器端预演与投影校正工具。TypeScript + WebGL2,无需后端,数据保存在浏览器 localStorage。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建 (dist/)
npm test           # 数学层单元测试 (vitest)
```

## 功能

| 页面 | 功能 |
|------|------|
| 节目列表 | 节目增删改复制,工程 JSON 导出/导入 |
| 场景编排 | 真实星表星空(926 颗 ≤4.5 等,HYG/Yale BSC)、日期时间/观测地可调;行星+轨道(JPL 开普勒根数);关键帧动画时间轴 |
| 投影校正 | 180°/210° 视场、球幕倾角、输出分辨率;多投影机分区、边缘融合带宽度/伽马/增益,分区叠加与融合增益热力图 |
| 座位预览 | 从任意座位透视看球幕内壁,直观检查实际变形,视线可拖动 |
| 渲染导出 | 等距鱼眼 domemaster PNG 序列,逐帧渲染打包 ZIP,带进度与取消 |
| 设置 | 渲染参数、鱼眼映射精度自检、存储管理 |

## 鱼眼映射(核心)

- 输出为标准等距鱼眼 domemaster:`r = (θ / (fov/2)) · (size/2)`,方位角北起顺时针,图像上方为正北。
- 渲染管线:场景 → 立方体贴图 6 面 → 合成 pass 用**解析公式逐像素**映射,精度不依赖几何细分。
- CPU 参考实现在 `src/core/fisheye.ts`,GLSL 端公式与其逐字对应。
- 倾角约定:正值 = 球幕天顶轴向观众席(图像下方)倾斜。
- **精度验证**:设置页「运行自检」用 GPU 实际渲染方向编码图并逐像素读回,与 CPU 公式核对。实测最大误差 ≈ 0.05 像素(要求 < 0.5 像素),覆盖 180°/210° × 倾角 0°/15°/30°。

## 星表更新

```bash
npm run fetch-stars   # 从 HYG 数据库重新拉取并过滤到 4.5 等, 生成 src/data/stars.json
```

## 目录结构

```
src/
  core/       鱼眼映射、天文计算、关键帧、数据模型、本地存储
  render/     WebGL2 渲染器(立方体贴图+鱼眼合成)、座位透视、融合计算、PNG 导出、精度自检
  ui/         路由、控件库、六个页面
  data/       星表 (stars.json)
test/         鱼眼与天文计算单元测试
scripts/      星表抓取脚本
```
